One engine, two templates

Both pages below are made by the same D code, with the same data. The only thing that changes is the html template.

Tableviews/table.html Cardsviews/cards.html

The templates are plain html: no {{ }}, no {% for %}, no code inside. Open them in a browser or in any html editor: they show example content and they are valid html. Here they are, as the designer wrote them, before the code fills them: table.html and cards.html.

  • The code looks for ids and classes. The designer can move an element, change its tag or restyle the whole page: as long as the id stays, it works. One template uses a table, the other a grid of divs.
  • Lists: the first example row in the template is cloned for each book, the example rows are removed.
  • Optional parts are removed when they are not needed: the offer banner after a search, the results when there are none, "Details" or "Sold out" on each book.
  • Escaping is automatic: texts are set as texts, never read as html. Try searching for <script>alert(1)</script>.
  • The templates are parsed at compile time: each request just gets a fresh copy of the tree.
