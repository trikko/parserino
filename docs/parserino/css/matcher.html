    Module parserino.css.matcher

    Matching of CSS selectors against the DOM.

    Complex selectors are matched right to left, with backtracking on the descendant and subsequent-sibling combinators. :has() is matched forward.

    Functions

    NameDescription
    matches(list, node, scopeElement) Does the element match any selector of the list? scope is the element matched by :scope (the root of the query).
    matchesLastCompound(list, item, node, scopeElement) Does the element match the last compound of the selector item of the list? (a quick test)
