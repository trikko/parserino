    Struct Buffer

    A growable array for temporary data (malloc'd, GC in CTFE). If memory runs out, the items are not added and failed becomes true (and stays true): the owner checks it at the end of its work, as it checks the results of the Arena.

    struct Buffer(T);

    Fields

    NameTypeDescription
    failed boolMemory ran out: some items were not added

    Properties

    NameTypeDescription
    empty[get] boolIs it empty?
    length[get] size_tNumber of items

    Methods

    NameDescription
    clear () Remove all the items (the memory is kept)
    opIndex (i) The item at index i
    opSlice () The items (a slice of the buffer: valid until the next put)
    put (x) Append an item
    put (xs) Append many items at once
    putLower (s) Append s in ASCII lowercase
    removeLast () Remove the last item
    shrinkTo (n) Keep only the first n items
