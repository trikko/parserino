    Struct Arena

    The bump allocator: memory comes from zeroed blocks (4 KB, doubling up to 16 KB, or bigger for a bigger allocation) that are freed all together by release or the destructor. An Arena can't be copied.

    struct Arena;

    Methods

    NameDescription
    alloc (n) Allocate n zeroed Ts. It returns null if out of memory.
    dup (src) Copy an array into the arena.
    make () Allocate a single zeroed T.
    release () Free everything.
    reserve (bytes) Make room for bytes more bytes in a single block (when the total is known in advance)
