    Module parserino.names

    Names of tags, attributes and namespaces.

    Known names have a fixed id (Tag, AttrName); other names get an id when a document meets them (see NameTable). Generated by tools/gen/gen_names.py (the lists come from lexbor, Apache-2.0: see NOTICE-lexbor).

    Functions

    NameDescription
    hash(s) FNV-1a
    knownAttr(name) Id of a known attribute (name must be lowercase), or AttrName.Undef
    knownTag(name) Id of a known tag (name must be lowercase), or Tag.Undef

    Structs

    NameDescription
    NameTable Interned names of a document: known names have their static id, the others get new ids (from first on) the first time they are seen.

    Enums

    NameDescription
    AttrName Known attributes. Unknown names get ids from AttrName.Last on. The members are the names in PascalCase (accept-charset is AcceptCharset); Undef is no attribute.
    Category Categories of the tags in the tree construction ("special", "formatting", scopes, ...)
    Ns Namespaces. None is no namespace (as for most attributes); nothing uses Any.
    Tag Known tags. Unknown tag names get ids from Tag.Last on. The members are the names in PascalCase (annotation-xml is AnnotationXml); Undef (no tag), EndOfFile and the ...Node members name the nodes that are not elements.

    Global variables

    NameTypeDescription
    attrNames immutable(char[][73]) Names of the known attributes
    tagCategories immutable(ubyte[8][199]) Categories of each tag, for each namespace
    tagNames immutable(char[][199]) Names of the known tags (lowercase)
