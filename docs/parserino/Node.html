    Struct Node

    A node of a document: an element, a text, a comment, a doctype, the document itself, ... See the module documentation for the navigation (Show) and the rules on errors.

    struct Node;

    Properties

    NameTypeDescription
    dataView[get] const(char)[]The data of a text, comment or processing instruction without copying it; null for other nodes
    isComment[get] boolIs this a comment?
    isElement[get] boolIs this node an element?
    isText[get] boolIs this a text node?
    isValid[get] boolIs this a valid node?
    nodeName[get] stringThe name of the node, as in the DOM: the tag name for elements (uppercase for html
    nodeType[get] NodeTypeThe type of the node (NodeType.Element, NodeType.Text, ...)
    ownerDocument[get] DocumentThe document of this node
    textContent[get] stringThe text of the node (DOM textContent): the text of all the descendants for elements and fragments, the data for texts, comments and processing instructions, null for the document and the doctype.
    textContent[set] const(char)[]Set the text: for elements and fragments it replaces all the children with a text node, for texts, comments and processing instructions it replaces the data. It does nothing on the document and the doctype (as in the DOM).

    Methods

    NameDescription
    after (what) Insert a node (or a text, or a fragment) after this one
    append (what) Append a node (or a text, or a fragment) as the last child. Strings become text nodes; "<b>x</b>".asFragment is parsed as html (in the context of this element); a DocumentFragment (see Document.fragment) gives its children.
    appendChild (child) Append a child node (as append, only for nodes)
    asElement () This node as an Element, or an invalid element if it isn't one
    before (what) Insert a node (or a text, or a fragment) before this one
    byClass (name) Search for elements by class
    byComment (text) Search for comments by text (whitespace at the ends ignored)
    byCommentExact (text) Search for comments with exactly this text
    byId (id) Search for an element by id. It returns an invalid element (== null) if not found.
    bySelector (selector) Search for elements by css selector
    bySelector () ditto, parsed at compile time
    byTagName (name) Search for elements by tag name (case-insensitive for html elements; "*" gives all the elements)
    children () The children that match show, as a lazy (bidirectional) range
    contains (other) Is other this node or one of its descendants? (as in the DOM)
    descendants () All the descendants that match show, in tree order, as a lazy (bidirectional) range
    dup () A deep copy of this node (with all the descendants), not attached to the document
    firstChild () The first child that matches show
    hasChildNodes () Does this node have children? (any kind of node)
    lastChild () The last child that matches show
    nextSibling () The next sibling that matches show
    opAssign (__param_0) node = null makes it an invalid node (it releases its document)
    opCast () cast(string) node is the same as toString
    opEquals (e) node == null is true for an invalid node, node == "..." compares the html of the node, node == other is true if they are the same node.
    opOpAssign (what) node ~= x is node.append(x)
    parent () The parent, if it matches show (else an invalid node). By default the parent element: the parent of <html> is the document, so html.parent is invalid and html.parent!(Show.All) is the document.
    prepend (what) Insert a node (or a text, or a fragment) as the first child
    previousSibling () The previous sibling that matches show
    remove () Remove this node from its parent. The node is still valid and can be inserted again. It returns false if the node had no parent.
    replaceWith (what) Replace this node with another one (or with a text, or a fragment)
    shallowDup () A copy of this node alone (for an element: the tag and the attributes, without children)
    toHash () Nodes can be keys of associative arrays (the same node, the same key)
    toString () The node as html (for an element: outerHTML)
    toString (sink) Write the node as html to a sink
