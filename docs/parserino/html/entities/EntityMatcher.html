    Struct EntityMatcher

    Incremental matching of a name, one char at a time: entities[lo .. hi] are the names starting with the chars seen so far. It works across input chunks.

    struct EntityMatcher;

    Fields

    NameTypeDescription
    best ulongthe longest full match so far (index in entities)
    bestLength ulongits length
    depth ulongchars seen
    hi ulongthe names still possible: entities[lo .. hi]
    lo ulongthe names still possible: entities[lo .. hi]

    Methods

    NameDescription
    put (c) Feed one char. It returns false when no name can match anymore.

    Example

    EntityMatcher m;
foreach (char c; "notin;") if (!m.put(c)) break;
assert(entities[m.best].name == "notin;");
assert(entities[m.best].value == "\u2209");

EntityMatcher m2;
foreach (char c; "notit;") if (!m2.put(c)) break;
assert(entities[m2.best].name == "not");
