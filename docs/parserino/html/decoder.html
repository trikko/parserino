    Module parserino.html.decoder

    UTF-8 decoding of the input, as the Encoding standard (the "UTF-8 decode" of the HTML parser): invalid bytes become U+FFFD (one for each "maximal subpart", as browsers do) and a leading byte order mark is removed. The input comes in chunks: a sequence can span two chunks.

    Functions

    NameDescription
    validLength(s, hasCR) The length of the longest prefix of s that is valid and complete UTF-8. hasCR tells if that prefix contains a '\r' (the tokenizer normalizes newlines): one pass for both. ASCII runs are checked 16 bytes at a time.
