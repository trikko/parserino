    Module parserino.html.parser

    The HTML parser: tokenizer + tree builder, for documents (also chunk by chunk) and fragments.

    Functions

    NameDescription
    freeParser(p) Free a parser made by newParser
    newParser() A parser on the heap (it must not move), initialized
    parseDocument(doc, html) Parse a whole document into doc (an empty document)
    parseFragment(doc, context, html) Parse a fragment in the context of context (an element of doc). It returns a detached <html> element whose children are the result, or null if out of memory.

    Structs

    NameDescription
    Parser A parser. It must not be moved after begin (the tokenizer points to the tree builder): keep it in memory that doesn't move (heap, or a local variable used in place).
