    Struct Tokenizer

    The tokenizer: feed it the input, then finish

    struct Tokenizer;

    Constructors

    NameDescription
    this (document, sink) Tokens go to sink; the tag names are interned in document

    Fields

    NameTypeDescription
    collectErrors boolCollect the parse errors in errors (off by default: then they cost nothing)
    decoder Utf8DecoderThe UTF-8 decoding of the input (set decoder.stripBom for documents)
    errors Buffer!(parserino.html.errors.RawParseError)The parse errors found so far (with collectErrors), in the order they were found
    failed boolOut of memory (or stopped by the sink)

    Methods

    NameDescription
    error (code) A parse error at the current position (the tree builder reports its errors here too)
    feed (chunk) Tokenize a chunk. It returns false on errors (out of memory).
    finish () End of input: the pending data is completed and an EOF token is emitted
    setLastStartTag (name) Set the last start tag, which closes RCDATA, RAWTEXT and script data (for tests of the tokenizer alone)
    switchTo (s) Set by the tree builder, while it processes a start tag (or before the input for fragments). For RCDATA, RAWTEXT and script data, the current start tag is the one that closes them.
