    Module parserino.dom

    The document tree.

    Every node lives in the arena of its document and is freed with it: removed nodes stay valid. Nodes are plain structs: DomElement, DomCharacterData, ... start with a DomNode: node.as!DomElement (after checking type) gives the struct that contains it.

    Functions

    NameDescription
    textContent(node, sink) The text of a node and its descendants (DOM textContent) written to sink
    toLower(s, buf, big) ASCII lowercase: s itself if already lowercase, else a copy in buf, or in big for long names. It returns null only if out of memory.

    Structs

    NameDescription
    DomAttribute An attribute
    DomCharacterData Text, comments, processing instructions, CDATA sections
    DomDocument The document: it owns the memory of all its nodes (and the names it meets). It can't be
    DomDocumentFragment A fragment, or the content of a <template>
    DomDocumentType A doctype: <!DOCTYPE name PUBLIC "publicId" "systemId">
    DomElement An element
    DomNode The common part of all the nodes
