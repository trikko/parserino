    struct DomNode;

    Fields

    NameTypeDescription
    document DomDocument*The document that owns the node
    firstChild DomNode*First child
    lastChild DomNode*Last child
    name uintTag of elements (a Tag or an id from the document names). Other nodes: Tag.TextNode, Tag.CommentNode, ...
    next DomNode*Next sibling
    ns NsNamespace of elements
    parent DomNode*null for detached nodes and roots
    prev DomNode*Previous sibling
    type NodeTypeThe node type

    Methods

    NameDescription
    appendChild (child) Append child as the last child (child must be detached)
    as () The struct that contains this node: DomElement, DomCharacterData, DomDocumentType, DomDocumentFragment or DomDocument. type must match (checked only by an assert).
    asCharacterData () The element / character data, or null if the node is something else
    asElement () The element / character data, or null if the node is something else
    contains (other) Is other this node or one of its descendants?
    firstChildOrContent () The first node of the template content for a <template>, else the first child
    insertAfter (node) Insert node (detached) after this node
    insertBefore (node) Insert node (detached) before this node
    isBlank () Like isEmpty, but text made only of whitespace doesn't count either (the :blank selector)
    isCharacterData () Is it text, a comment, a processing instruction or a CDATA section?
    isEmpty () Does it have no children that are elements or non-empty text? Comments and processing instructions don't count (as for the :empty selector).
    isHtml (tag) Is this an element in the html namespace with this tag?
    localName () Local name ("div", "#text", "!--", ...; the target for processing instructions)
    moveChildrenTo (to) Move all the children of this node at the end of to
    nextElement () Previous/next sibling that is an element
    nextInTree (root) Next node in tree order inside root (excluded), or null
    nextSkippingChildren (root) Next node in tree order after this subtree, inside root, or null
    parentOrHost () The parent, or the <template> for the nodes of a template content
    prevElement () Previous/next sibling that is an element
    remove () Detach this node from its parent
