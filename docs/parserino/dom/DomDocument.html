    Struct DomDocument

    The document: it owns the memory of all its nodes (and the names it meets). It can't be

    struct DomDocument;

    Fields

    NameTypeDescription
    arena ArenaThe memory of the nodes, attributes and strings
    compatMode CompatModeThe quirks mode
    doctype DomDocumentType*The doctype, or null
    node DomNodeThe common part (alias this)
    scripting boolParsed as with scripting enabled (<noscript> is raw text)

    Methods

    NameDescription
    attrId (lowerName) Attribute id of a lowercase name, adding it if unknown. 0 if out of memory.
    attrName (id) The name of an attribute id
    body () The <body>: the first body or frameset child of the <html> root element (as in the standard)
    copy (s) A string owned by the document
    createAttribute (lowerName, value, ns) A new attribute (not attached). The name must be lowercase.
    createComment (data) A new comment (not attached), with a copy of data
    createDocumentType (name, publicId, systemId) A new doctype (not attached)
    createElement (tag, ns) A new element (not attached), with an empty content for a <template>. It returns null if out of memory, as the other create... functions.
    createFragment () A new empty fragment
    createProcessingInstruction (target, data) A new processing instruction (not attached)
    createText (data) A new text node (not attached), with a copy of data
    documentElement () The root element (<html>)
    findAttrName (name) Attribute id of a name (any case), 0 if the document never saw it
    findTagName (name) Tag id of a name (any case), 0 if the document never saw it
    head () The <head>: the first head child of the <html> root element (as in the standard)
    importNode (src, deep) A copy of src owned by this document. Deep: with all the descendants and the template contents; else only the node (and the attributes). It returns null if out of memory. The visit is iterative, so deep trees don't overflow the stack.
    initialize () Initialize a document allocated by the caller (zeroed memory)
    release () Free all the memory
    setAttribute (e, name, value) Set (or add) an attribute. The name is lowercased. It returns null if out of memory.
    tagId (lowerName) Tag id of a lowercase name, adding it if unknown. 0 if out of memory.
    tagName (id) The name of a tag id
