    Methods

    NameDescription
    copyFrom (e) Make this element a copy of another one: the tag, the attributes and the children
    dup () A deep copy of this element, not attached to the document
    getAttribute (attr) Get an attribute. It returns null if the attribute is missing.
    getAttributeView (attr) ditto, without copying
    hasAttribute (attr) Check if an attribute exists
    matches (selector) Does this element match a css selector?
    opAssign (html) Replace this element with the (single) element parsed from html: el = "<b>x</b>";
    opAssign (__param_0) element = null makes it an invalid element (it releases its document)
    opAssign (rhs) Copies refer to the same element
    removeAttribute (attr) Remove an attribute from this element
    setAttribute (name, value) Set an attribute for this element
    shallowCopyFrom (e) Make this element a copy of another one, without the children: the tag and the attributes
    shallowDup () A copy of this element alone: the tag and the attributes, without children
