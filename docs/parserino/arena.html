    Module parserino.arena

    A bump allocator: many small allocations, freed all together.

    It also works at compile time (CTFE), where it falls back to the GC, so the same parsing code can run both at runtime and at compile time.

    Functions

    NameDescription
    copyItems(dst, src, n) Copy n items (memcpy, a loop in CTFE)
    copyItems(dst, src, n) ditto, from mutable items (CTFE can't cast away the const of a pointer)

    Structs

    NameDescription
    Arena The bump allocator: memory comes from zeroed blocks (4 KB, doubling up to 16 KB, or bigger for a bigger allocation) that are freed all together by release or the destructor. An Arena can't be copied.
    Buffer A growable array for temporary data (malloc'd, GC in CTFE). If memory runs out, the items are not added and failed becomes true (and stays true): the owner checks it at the end of its work, as it checks the results of the Arena.
