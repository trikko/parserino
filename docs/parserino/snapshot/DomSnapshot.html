    Struct DomSnapshot

    A document as plain arrays (see the module): made by takeSnapshot, turned back into a document by restore

    struct DomSnapshot;

    Fields

    NameTypeDescription
    attributes SnapshotAttribute[]the attributes of the elements, in the same order
    compatMode CompatModeas DomDocument.compatMode
    nodes SnapshotNode[]all the nodes but the document, in tree order (template contents before the children)
    scripting boolas DomDocument.scripting

    Methods

    NameDescription
    restore (doc) Rebuild the tree into doc (an empty document). It returns false if out of memory. The document uses the strings of the snapshot without copying them: the snapshot must outlive it (a static one always does).
