    API documentation

    ModuleDescription
    parserino.css.matcher Matching of CSS selectors against the DOM.
    parserino.css.selector CSS selectors: syntax tree and parser.
    parserino.css.tokenizer CSS tokenizer (CSS Syntax Level 3), limited to what selectors need. It works at runtime and at compile time.
    parserino.html.decoder UTF-8 decoding of the input, as the Encoding standard (the "UTF-8 decode" of the HTML parser): invalid bytes become U+FFFD (one for each "maximal subpart", as browsers do) and a leading byte order mark is removed. The input comes in chunks: a sequence can span two chunks.
    parserino.html.entities Named character references of HTML (&amp;, &nbsp;, ...). Generated by tools/gen/gen_names.py (the list comes from lexbor, Apache-2.0: see NOTICE-lexbor).
    parserino.html.errors The parse errors of the HTML parser.
    parserino.html.parser The HTML parser: tokenizer + tree builder, for documents (also chunk by chunk) and fragments.
    parserino.html.serializer HTML serialization ("serializing HTML fragments" in the HTML spec).
    parserino.html.tokenizer HTML tokenizer (HTML Living Standard, "Tokenization").
    parserino.html.treebuilder HTML tree construction (HTML Living Standard, "Tree construction").
    parserino.arena A bump allocator: many small allocations, freed all together.
    parserino.dom The document tree.
    parserino.encoding Encodings other than UTF-8.
    parserino.names Names of tags, attributes and namespaces.
    parserino.snapshot A document tree as plain arrays, without pointers.
    parserino HTML5 parser and DOM manipulation library.
